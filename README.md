# Sales Recording App

A simple web-based sales recording system built with Python and Flask, developed for a programming assignment (ITS101D).

## Features

- Record a sale (item, price, quantity)
- Automatically calculate total sales, total units sold, and number of transactions
- Identify the best-selling item
- View all recorded transactions
- Generate a daily sales report (HTML table)
- Reset sales data

## Technologies Used

- Python
- Flask
- HTML
- CSS

## Project Purpose

This project was developed as part of a programming assignment to demonstrate practical use of Python and Flask for web development. It's a lightweight system that lets a shop owner record sales through a web page and instantly see a summary — total sales, units sold, and best-selling item — without needing a database or complicated setup.

## How to Run

1. Install Python.
2. Install Flask: `pip install flask`
3. Run the application: `python app.py`
4. Open: `http://127.0.0.1:5000`
